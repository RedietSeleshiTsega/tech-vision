# TechVision

Final integrated TechVision frontend built with Next.js 16, React 19, Tailwind CSS 4, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3009`.

## Main routes

- `/`
- `/courses`
- `/stories`
- `/pricing`
- `/login`
- `/signup`
- `/apply`
- `/dashboard`

See `FINAL_MERGE_NOTES.md` for merge details and prototype limitations.
